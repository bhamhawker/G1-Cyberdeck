# G1 CYBERDECK

A portable wireless Linux cyberdeck powered by a Raspberry Pi 3 Model A+ and an Innioasis G1 Android music player.

## 🚀 Project Overview

G1 Cyberdeck transforms the Innioasis G1 into a touchscreen display and controller for a Raspberry Pi running Linux.

The goal is to create a compact, portable computer with a custom interface, wireless connectivity, and offline capabilities.

## 🖥️ Hardware

| Component | Specification |
|---|---|
| Computer | Raspberry Pi 3 Model A+ |
| Display | Innioasis G1 |
| Android Version | Android 8.1 |
| Raspberry Pi OS | Raspberry Pi OS 32-bit Desktop |
| Storage | 128 GB microSD |
| Connection | Local Wi-Fi |
